# Multithreaded-logger - Многопоточная реализация записи сообщений в журнал


## Описание проекта

Этот репозиторий содержит исходные коды:
- **динамической библиотеки** для записи сообщений в файл;
- **приложения**, демонстрирующего работу библиотеки;
- **unit-тестов** для библиотеки.

Библиотека позволяет записывать сообщения разного уровня важности с меткой времени в журнал. Сообщения автоматически фильтруются по трём уровням важности:
- **INFO**
- **WARNING**
- **ERROR**.

*Например, если уровень важности по умолчанию - WARNING, то сообщения более низкого уровня (INFO) записываться в журнал не будут, а сообщения уровня WARNING или ERROR запишутся.*

Демонстрационное приложение работает в многопоточном режиме. Оно принимает сообщения от пользователя в одном потоке и записывает их в журнал в другом потоке. Передача сообщений происходит через потокобезопасную очередь.

## Установка и запуск

#### Установка зависимостей
Проект создавался для операционых систем **Ubuntu/Debian**.
Для сборки проекта потребуется установить зависимости: **git, make, g++**

```bash
sudo apt update && sudo apt install -y git make gcc g++
```

#### Сборка проекта
Чтобы установить проект, выполните следующие команды:
```bash
git clone https://github.com/Diukha/Multithreaded-logger.git
cd Multithreaded-logger/
make all
```
Также можно запустить автоматические тесты библиотеки, чтобы убедиться в корректности установки:
```bash
make tests
```

#### Запуск приложения
Запустить демонстрационное приложения можно, например, так:
```bash
./app --output out.txt --log-level WARNING
```

Также о флагах и аргументах приложения можно узнать из справки:
```bash
./app --help
```
